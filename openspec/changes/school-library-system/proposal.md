# Proposal: 学校图书借阅系统

## Why

学校图书馆需要一个支持管理员和读者（学生/教师）两种角色的 Web 借阅系统，替代人工登记方式，实现图书编目、借还流通、逾期罚款管理的数字化，让读者可以自助检索和查询借阅情况。

## What Changes

- 新建 Web 应用：Vue 3 前端 + Spring Boot REST API 后端 + MySQL 存储，前后端分离部署
- 提供两种角色的能力：
  - **读者端**：检索图书、查看可借状态、查看自己的借阅记录、续借
  - **管理端**：图书/副本编目与下架、读者账户管理、处理借出/归还、逾期与罚款处理、基础统计
- 实现借阅规则引擎：
  - 借阅上限：学生同时最多 5 本，教师最多 10 本
  - 借期：学生 30 天，教师 60 天
  - 续借：允许 1 次；该书被预约时不允许续借
  - 逾期：即将逾期前提醒；逾期后计罚款并限制借阅；缴纳罚金后解除限制
- 图书与副本分开建模：书目信息（ISBN/书名等）挂在"图书"，借还状态挂在每个"副本"
- 第二期范围（本变更不含，仅预留接口）：预约功能、统计报表、批量导入

## Capabilities

### New Capabilities
- `auth`: 管理员与读者（学生/教师）的认证与角色权限控制
- `book-catalog`: 图书书目与副本的管理（入库、编目、下架、检索）
- `reader-management`: 读者账户管理（学生/教师信息、账户状态）
- `circulation`: 借阅流通（借出、归还、续借、借阅规则校验）
- `overdue-penalty`: 逾期提醒、罚款与借阅限制、缴费解除

### Modified Capabilities
（无——全新项目，无既有规格）

## Impact

- 全新代码库：前端（Vue 3）、后端（Spring Boot）、数据库（MySQL）
- 无既有系统受影响
- 部署目标：学校内网服务器或云上单实例，浏览器访问
