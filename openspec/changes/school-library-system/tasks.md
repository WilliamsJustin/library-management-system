# Tasks: 学校图书借阅系统

## 1. 项目脚手架与基础设施

- [ ] 1.1 初始化 Spring Boot 项目（Web、Security、Validation、MySQL Driver、JPA/MyBatis），启动无报错
- [ ] 1.2 初始化 Vue 3 + Vite + Pinia + Vue Router + Element Plus 前端项目，`npm run dev` 可访问
- [ ] 1.3 编写 MySQL schema（book、book_copy、reader、loan、penalty，含唯一约束与乐观锁 version 字段），本地建库并验证执行成功
- [ ] 1.4 定义统一 API 错误响应结构（code/message）与全局异常处理器，用一个测试端点验证返回格式

## 2. 认证与角色（auth）

- [ ] 2.1 实现账号密码登录、JWT 签发与校验过滤器，登录/未登录场景的集成测试通过
- [ ] 2.2 实现 ADMIN/READER 角色权限控制及"读者仅能查本人数据"的资源所有权校验，越权请求返回 403 的测试通过
- [ ] 2.3 实现修改密码接口（校验原密码），测试覆盖成功与原密码错误场景
- [ ] 2.4 前端登录页、角色路由守卫、读者端/管理端双布局，验证错误角色被重定向

## 3. 图书编目（book-catalog）

- [ ] 3.1 实现书目 CRUD（必填校验：ISBN、书名），REST 测试覆盖新增成功与校验失败
- [ ] 3.2 实现副本管理（唯一条码号、状态 IN_STOCK/BORROWED/WITHDRAWN），同书目多副本场景测试通过
- [ ] 3.3 实现副本下架：已借出副本拒绝下架，测试通过
- [ ] 3.4 实现关键词检索（书名/作者/ISBN/分类）并返回可借副本数量，空结果与命中场景测试通过
- [ ] 3.5 前端管理端编目页面（书目+副本）与读者端检索页面，手工验证检索与编目流程

## 4. 读者管理（reader-management）

- [ ] 4.1 实现读者账户 CRUD（学生/教师身份、学号唯一约束），重复学号返回冲突的测试通过
- [ ] 4.2 实现读者账户状态（NORMAL/RESTRICTED）与身份类型变更，变更后借阅规则按新身份执行的测试通过
- [ ] 4.3 前端读者管理列表与编辑页面，手工验证创建/修改/状态展示

## 5. 借阅流通（circulation）

- [ ] 5.1 实现 CirculationPolicy 规则组件（限额 5/10、借期 30/60 天、续借 1 次、预约检查默认实现），单元测试覆盖全部规则分支
- [ ] 5.2 实现借出接口：事务内校验限额/副本状态并生成 loan（乐观锁防并发），测试覆盖学生/教师借期、超限拒绝、非在库拒绝
- [ ] 5.3 实现归还接口：事务内关闭 loan、更新副本状态，测试覆盖按期与逾期归还（逾期生成罚金）
- [ ] 5.4 实现续借接口，测试覆盖成功续借、二次续借拒绝、逾期记录拒绝、被预约拒绝（默认实现）
- [ ] 5.5 实现借阅记录查询（读者本人 / 管理员按读者或副本），权限与数据范围测试通过
- [ ] 5.6 前端管理端借还操作台与读者端"我的借阅/续借"页面，手工验证完整借还流程

## 6. 逾期与罚款（overdue-penalty）

- [ ] 6.1 实现每日定时任务：逾期 loan 置 OVERDUE、生成罚金（按 loan_id 幂等）、读者置受限，定时任务测试通过
- [ ] 6.2 实现即将逾期提醒（应还日期前 3 天，站内消息形式），读者登录可见提醒
- [ ] 6.3 实现罚金缴纳登记：全部账单结清后账户自动恢复正常，测试覆盖缴清解除与部分缴纳不解除
- [ ] 6.4 实现受限读者借书拒绝，测试通过
- [ ] 6.5 前端管理端罚款处理页面与读者端提醒/罚金展示，手工验证逾期-罚款-缴费-解除全流程
