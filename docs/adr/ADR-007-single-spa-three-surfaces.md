# ADR-007: 三端共存于同一个 SPA

- 状态：已采纳（2026-09，系统初版期；2026-09 响应式/主题改版进一步验证）

## 背景

系统有三类使用面：公共前台（访客）、读者后台（学生/教师）、管理后台（管理员）。备选：三个独立前端应用 vs 一个 SPA 内按路由分区。

## 决策

**同一个 Vue SPA**，`views/site`、`views/reader`、`views/admin` 三目录分区，`router` 守卫按 `requiresAuth + role` 拆分入口；登录后按角色路由到对应端（ADMIN→/admin，READER→/reader），头部"进入前台/进入后台"互跳。

## 后果

- ✅ 设计令牌、MobileCardList、DateRangeCombo、useBreakpoint 等共享层天然复用（响应式与两次换肤都吃到红利）
- ✅ 一次构建一个产物，Nginx 容器零特殊配置；角色切换无跨站跳转
- ✅ 登录态（Cookie 会话）天然同域共享
- ⚠️ 单包体积随三端增长（对课程规模无感；真要优化可路由级懒加载，已按 `() => import()` 落实）
- ⚠️ 三端耦合在一个发布单元——一端改版全量发布。接受：后端契约稳定，前端发布本就整体原子
- ❌ 被否备选：拆三个应用（共享层要抽包发布，协作与部署成本对单人项目不成比例）
