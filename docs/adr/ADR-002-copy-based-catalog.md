# ADR-002: 馆藏按副本（book_copy）两级建模

- 状态：已采纳（2026-09，系统初版期）

## 背景

图书流通的最小实体是**物理册**而不是书目：同一 ISBN 有多本，各自有独立条形码、馆藏位置与借阅历史；"可借 2/共 3"是派生值不是权威数据。

## 决策

`book`（书目元数据，ISBN 唯一）与 `book_copy`（物理副本，条形码唯一，状态 IN_STOCK/BORROWED/WITHDRAWN + 乐观锁）两级建模。借阅记录挂在 copy 上；可借数量实时由副本状态推导。

## 后果

- ✅ 条码即借阅凭据：柜台场景"账号+条码"代借、自助场景选副本借出，都可追溯到具体物理册
- ✅ 并发正确性：副本行乐观锁天然防同一册超借
- ✅ 单册逾期/罚款语义清晰（一笔借阅一张罚单）
- ⚠️ 比单纯"书目+库存数"多一层；导入/编目要逐副本登记条码。备选方案（书目上存库存数）被否：无法表达"哪一本在谁手里"，条码追溯与并发扣减都做不了
